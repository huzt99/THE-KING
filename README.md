UniRouter Manager (Hussein Net) 🌐🚀
​تطبيق ذكي واحترافي مصمم خصيصاً لإدارة شبكات الإنترنت، صيانة الراوترات، ومتابعة المشتركين عن بُعد لصالح حسين لخدمات الإنترنت (Hussein Net).
​🛠️ المميزات والخصائص الرئيسية:
​إدارة المشتركين والوصول عن بُعد (Remote Access):
​تخزين وعرض بيانات المشتركين (الاسم، رقم الهاتف، نوع الراوتر).
​التحكم والوصول المباشر لراوتر المشترك أو صحن النانو (Nano / AirOS) إما محلياً (صيانة ميدانية) أو عن بُعد عبر الـ (Remote IP / VPN) من مقر العمل.
​أداة التشخيص واختبار البنج (Ping Diagnostics):
​فحص سرعة الاستجابة (ms) واستقرار الاتصال لأي جهاز أو مشترك.
​رصد وفحص حزم البيانات المفقودة (Packet Loss) لمعالجة سوء الخدمة بدقة.
​فحص الشبكة المحلية (Network Scanner):
​اكتشاف الأجهزة المتصلة بالنطاق (الراوتر الرئيسي، أجهزة النانو، وأجهزة الـ FTTH ONU).
​الهوية والتصميم (Glassmorphism & Branding):
​واجهة مستخدم عصرية بتصميم داكن (Glassmorphism) تحمل الهوية الرسمية لشبكة حسين نت وشعار "طبيب الطاعون".
​تكامل مدمج مع أيقونات التطبيق الرسمية (flutter_launcher_icons) وإشعارات بوت التليجرام.
​💻 التقنيات المستخدمة (Tech Stack):
​Framework: Flutter (Dart)
​Networking & Tools: url_launcher, dart_ping, http, network_info_plus, shared_preferences, crypto.
